01 / What we monitor

Everything that keeps your clusters and servers running

Kept up to date automatically, for every cluster and server you connect.

Pods

  • • Live health: status, restarts, CPU and memory for every pod.
  • • Problems flagged for you: crashes, out-of-memory kills and pods that won’t start.
  • • The reason, not just the error: the last log lines of a failing pod, right next to it.

Jobs

  • • Full picture: every job and scheduled job with its latest result.
  • • Spot failures: see at a glance which jobs failed or never finished.
  • • Less noise: repeat runs are grouped, so a job only shows as failed when its last run failed.

Nodes

  • • Capacity vs. usage: how much CPU and memory each machine has and how much is in use.
  • • Health: which machines are ready and which aren’t.
  • • Crowding: how full each machine is, so you see pressure before it hurts.

Servers

  • • Live health: CPU, memory, disks, load and network for every Linux server.
  • • Problems flagged for you: disks filling up, memory pressure, failed services and recent reboots.
  • • Error logs: the latest errors from the system log, right next to the problem.

GPUs

  • • Use and memory: how busy each GPU is and how much of its memory is taken.
  • • Heat and power: temperature and power draw, with a warning when a card runs hot.
  • • NVIDIA and AMD: read straight from the card’s own driver.

History

  • • A week of charts: CPU, memory, disk, load, network and GPUs for the last hour, day or week.
  • • Average and peak: point at any moment to see both.
  • • Gaps show downtime: see exactly when a server stopped reporting.

Health

  • • One list of what’s wrong: problems and warnings across the cluster, newest first.
  • • Incidents: problems are grouped into incidents you can follow until they’re resolved.
  • • Explained: one click for a plain-language look at what happened and how to fix it.

Leaked secrets

  • • Passwords and keys in the open: flagged when they show up in app output or settings.
  • • Detected, not copied: we show where a secret leaked and a short masked hint, never the secret itself.
  • • How to fix it: every finding comes with the next step to take.

Changes

  • • Nothing changes on its own: fixes only happen after you approve them.
  • • Full history: every approval, change and pause, with who did it and when.
  • • Easy to undo: the previous settings are kept for every change.
